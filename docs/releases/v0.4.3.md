# ShakeSpot 0.4.3 试用版

本次修复经过分栏、悬浮按钮和文本区域时丢失放大效果的问题。适用于 **Windows 11 x64**，沿用原有配置。

**下载与升级**

1. 下载下方 Assets 中的 **`ShakeSpot-0.4.3-win-x64.zip`**。`Source code` 是源码，普通使用无需下载。
2. 从托盘退出旧版，将 ZIP 解压到固定目录，运行 `ShakeSpot.exe`。
3. 快速往返晃动鼠标即可放大指针；双击托盘图标打开设置。移动程序路径后，若启用过开机启动，请重新保存该选项。

旁边的 `.zip.sha256` 用于校验下载文件；包内包含中文使用说明、构建信息与许可证。

**本次修复**

- 修复甩动恰好在应用私有分栏光标上达标时，触发被丢弃的问题。
- 经过分栏时保留手势和效果计时，返回普通区域直接显示当前放大帧，无需重新甩动。私有分栏图标本身保持原样，效果正常到期。
- 包含 0.4.2 的悬浮切换修复：箭头、手形、文本等标准光标预先同步同一帧，减少角色切换时闪回小光标。
- 保留点击、拖拽、隐藏光标、暂停、排除应用及异常退出时的恢复。

**验证与占用**

54 项 Rust 测试、124 项本机桌面检查、格式与 Clippy 检查通过；发布程序的启动、暂停、恢复启用及退出检查通过。16 轮交替标准/私有光标触发后，主进程和恢复进程的 GDI、USER 对象与内核句柄回到基线，热路径微基准堆分配为 0。

本机约 10 秒跨分栏对照中，两进程合计 CPU 时间由 0.156 秒变为 0.016 秒；新版工作集约 21.6 MiB、私有提交约 4.16 MiB，分别增加约 0.36、0.35 MiB。短测有波动，不代表固定比例的性能收益。没有新增覆盖层、常驻线程或高频计时器。环境、测量口径、最终发布核验及原始结果说明见 [0.4.3 验证记录](https://github.com/CELLOPOI/ShakeSpot/blob/v0.4.3/validation/SPLITTER-FIX-0.4.3.md)。

**使用边界**

应用私有光标本身不会放大；本轮使用自建窗口验证同类分栏机制，未直接自动验收 Codex 的具体控件。混合 DPI 多屏、物理高回报率鼠标、远程桌面和长期运行仍需更多反馈。本版本尚未签名，独占全屏游戏和安全桌面不在支持范围。

正常退出会恢复指针；整个进程树被强制结束后，可重新运行程序或执行 `ShakeSpot.exe --restore`。问题反馈请提交到 [Issues](https://github.com/CELLOPOI/ShakeSpot/issues)，附上 Windows 版本、显示缩放、复现步骤及暂停或退出后是否恢复。
