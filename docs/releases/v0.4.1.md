# ShakeSpot 0.4.1

Windows 11 x64 鼠标定位工具。快速左右、上下或斜向往返晃动鼠标，真实系统指针会平滑放大为黑色、白色描边的大箭头，随后恢复。普通用户权限运行，无需网络、账户或额外运行时。

下载 `ShakeSpot-0.4.1-rust-win-x64.zip`，解压到固定目录后运行 `ShakeSpot.exe`。托盘右键可暂停、设置、预览、恢复指针或退出；双击打开设置。压缩包旁的 `.sha256` 文件用于核对下载内容。

本版本增加手势必要条件预筛，降低日常无效移动的检测成本。与 0.4.0 对照的 1,161,102 个样本保持相同触发结果；同机微基准中，无效轨迹耗时降低约 94%～97%，有效水平晃动耗时增加约 4%。检测器仅增加 8 字节状态，热路径保持零堆分配。上述比例描述检测函数，整程序 CPU 和内存仍处于旧版量级。

已完成 54 项 Rust 测试、86 项本机桌面检查、格式和 Clippy 检查，以及发布程序启动和退出检查。详细数据随包附在 `RUST-VALIDATION.md`。

支持应用排除、按键阻断、连续晃动延长效果和独立恢复进程。设置沿用 `%LOCALAPPDATA%\ShakeSpot\native-settings.ini`。升级前先退出旧实例；移动 EXE 后，如已启用开机启动，请在新位置重新保存启动选项。

当前为未签名的便携版本，尚无安装器和自动更新。最大指针高度 256 物理像素，应用私有光标跳过放大；混合 DPI 多屏、物理高回报率鼠标、远程桌面和长期运行仍需更多环境验证。独占全屏游戏和安全桌面不在支持范围。必要时可在 EXE 所在目录运行 `./ShakeSpot.exe --restore` 恢复系统指针。
