# ShakeSpot 0.4.1 试用版

晃动鼠标，找到指针。适用于 **Windows 11 x64**，无需安装器、管理员权限、网络或额外运行库。

这是首次公开试用版，欢迎反馈触发手感、误触和不同鼠标/显示器环境下的表现。

**下载与运行**

1. 在下方 Assets 下载 **`ShakeSpot-0.4.1-win-x64.zip`**。`Source code` 是源码，普通使用无需下载。
2. 将整个 ZIP 解压到固定文件夹，双击 **`ShakeSpot.exe`**。
3. 快速左右、上下或斜向往返晃动鼠标，真实系统指针会平滑放大并自动恢复。

托盘图标可能收在右下角“隐藏的图标”中。双击可打开设置，右键可暂停、预览、恢复指针或退出。包内的“使用说明.txt”包含详细操作和移除方法；旁边的 `.sha256` 附件用于校验 ZIP。

**功能与本次优化**

- 默认灵敏度 3/5、最大倍率 4、持续时间约 1.1 秒，开机启动默认关闭。
- 按住鼠标键时不触发，点击或拖拽会结束效果，持续晃动会延长效果。
- 支持按程序名或完整路径排除前台应用；指针到达屏幕边缘后仍能识别相对甩动。
- 增加手势必要条件预筛，减少无效移动计算。与 0.4.0 对照的 1,161,102 个输入样本保持相同触发结果。

同机微基准中，无效轨迹检测耗时降低约 94%～97%，有效水平晃动耗时增加约 4%。检测器增加 8 字节状态，热路径保持零堆分配；整程序 CPU 和内存仍在旧版量级。

已完成 54 项 Rust 测试、86 项本机桌面检查、格式和 Clippy 检查，以及发布程序启动和退出检查。详细环境与结果见 [验证记录](https://github.com/CELLOPOI/ShakeSpot/blob/v0.4.1/RUST-VALIDATION.md)。

**试用须知与反馈**

本版本尚未签名，Windows 可能显示下载来源或未知发布者提示。支持标准系统光标，部分应用自定义光标不会放大；最大高度 256 物理像素。混合 DPI 多屏、物理高回报率鼠标、远程桌面和长期运行仍需更多验证。独占全屏游戏和安全桌面不在支持范围。

正常退出会恢复指针。如果整个进程树被强制结束后仍未恢复，可重新启动程序，或在 EXE 所在目录运行 `./ShakeSpot.exe --restore`。升级前退出旧实例；移动程序后，如启用过开机启动，请重新保存此选项。

反馈可提交到 [Issues](https://github.com/CELLOPOI/ShakeSpot/issues)，请附上 Windows 版本、显示缩放、鼠标 DPI（如果知道）、复现步骤，以及暂停或退出后是否恢复。
